# 溧水区街景工作台

南京市溧水区全域街景采集与可视化在线页面。

- `index.html`：工作台，支持百度/腾讯数据筛选、底图切换、街景跳转与道路链路。
- `lishui-tencent-panoramas-part-01.json` … `-05.json`：腾讯街景点位分片（共 80165 条）。
- `lishui-tencent-lines.geojson`：按拍摄顺序连接的道路链路。
- `s341-baidu-panoramas.json`：S341 百度街景点位。
- `s341-tencent-panoramas.json`：S341 腾讯街景点位（早期版本）。

行政边界来自 OpenStreetMap relation 2147643（ODbL）。
